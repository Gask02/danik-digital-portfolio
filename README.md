# Данияр · Danik Digital

## Автоматизация документов и анализ данных

Разрабатываю прикладные инструменты для работы с документами и данными. Использую ИИ-ассистентов в разработке и проверяю результат на конкретных сценариях.

Этот репозиторий — портфолио с описанием работы и демонстрацией. Исходный код приложения здесь не опубликован.

## Procure Lens — помощник закупщика

Демонстрационный прототип для сравнения предложений поставщиков с техническим заданием.

В показанном сценарии приложение:

- сравнивает три предложения с требованиями;
- показывает расхождения со ссылками на исходные строки документов;
- помогает подготовить 17 уточняющих вопросов.

**[Посмотреть демонстрацию на английском — около 2 минут](https://clips.agent-native.com/r/BJPdjb88YpaJ)**

Демонстрация использует вымышленных поставщиков и синтетические документы. Окончательное решение остаётся за человеком: приложение не отправляет заказы, не проводит платежи и не отправляет сообщения поставщикам.

### Статус и ограничения

Проект представлен на конкурсе Builder.io Agent-Native в ноябре 2026 года; получение заявки было подтверждено организатором. Это демонстрационный прототип, а не заявление о победе, промышленном внедрении или полной готовности для реальных закупок.

Видео показывает конкретный подготовленный сценарий. Оно не подтверждает загрузку произвольных документов, промышленную защищённость или проверку всех возможных случаев.

## Подход к работе

Конкретная задача, проверяемый результат и понятные ограничения. Для инструментов с ИИ важны возможность сверить вывод с исходными данными и сохранение контроля за человеком.
